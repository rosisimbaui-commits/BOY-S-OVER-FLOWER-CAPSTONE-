Digitizing Production: Real-Time Yield Analytics and Extraction Efficiency Monitoring System for AlDi Foods Inc.
The Digitizing Production: Real-Time Yield Analytics and Extraction Efficiency Monitoring System for AlDi Foods Inc. was a web-based application developed to replace the company’s manual production monitoring process. It centralized production records, automated yield and extraction efficiency computations, provided real-time dashboard analytics, and generated production reports to improve operational efficiency and support data-driven decision-making.

Features
Production Monitoring: Recorded production batch information, including production date, raw material quantity, operator details, and production output.
Real-Time Yield Analytics: Automatically computed production yield percentage and extraction efficiency while presenting the results through dashboards, charts, and summary tables.
Automated Report Generation: Generated daily, weekly, monthly, quarterly, and yearly production reports with historical data retrieval for monitoring and decision-making.
Production Stability Monitoring: Automatically classified production batches as Stable or Not Stable based on predefined production thresholds.
Centralized Database Management: Stored and managed production records securely in a centralized MySQL database for efficient retrieval and analysis.
Administrator Authentication: Provided secure login and user authentication to ensure that only authorized personnel could access and manage production data.

Backend: PHP

Data Visualization: Chart.js
Web Server: Apache (XAMPP)

## Getting Started

Follow these steps to set up and run the project on your local machine.

### Prerequisites

Install the following software before running the project:

- XAMPP (Apache and MySQL)
- PHP
- MySQL
- Visual Studio Code
- Git (optional)
- Google Chrome or Microsoft Edge

```bash
php -v
mysql --version
git --version
```

### Installation

1. Clone the repository.

```bash
git clone https://github.com/your-username/production-monitoring-system.git
```

2. Move the project folder to the **htdocs** directory inside your XAMPP installation.

```text
C:\xampp\htdocs\
```

3. Open the XAMPP Control Panel and start **Apache** and **MySQL**.

4. Create a MySQL database (e.g., `aldi_production_db`).

5. Import the provided SQL database file into the database using **phpMyAdmin**.

6. Update the database connection settings if necessary.

7. Open your web browser and run the application.

```text
http://localhost/production-monitoring-system/
```

8. Log in using an administrator account to access the system.
